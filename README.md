# KeepUpBar releases

This repository is the public home for KeepUpBar downloads and release notes.

## Download

Visit the [Releases page](https://github.com/ziadh/KeepUpBar-releases/releases) to find published builds. Open a release to see its notes and available download files.

No releases have been published yet. Check back here for the first build.

## Report a problem

If a download, installation, or update fails, [open an issue](https://github.com/ziadh/KeepUpBar-releases/issues) with your operating system, the release version, and the steps to reproduce the problem.
